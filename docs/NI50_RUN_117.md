# 50 um Ni profile and run 117 follow-up

Run 117 used the old 100 um Ni feed-forward table. Around a 160 C target,
that table supplied 64 mA bias while the wire used about 20-25 mA. The controller
had to subtract about 40 mA through its integral correction. Temperature and
current oscillations grew during the ramp.

The run stopped after 17.18 minutes with target 189.78 C and last accepted
filtered temperature 187.09 C (raw 190.33 C). Resistance rose from 18.511 to
18.817 Ohm, crossing the 1.5% jump trigger. Ten consecutive failed retry cycles
held 28 mA while candidate indicated temperatures rose from 196 to 229 C,
then the invalid-feedback shutdown fired. This was not an electrical limit.

## Table and controller

The table uses complete 10 C target bins to include both halves of the
oscillation. It pairs RMS **applied command** with mean accepted indicated
temperature. It excludes the first 120 seconds, invalid feedback and meter
range-change transients. Derived bins cover about 54-184 C. The 23 C / 5 mA
startup anchor and interpolation below the first bin are provisional choices.

Above the last derived bin, a positive linear fit of current squared versus
indicated temperature over the last eight bins supplies an explicitly estimated
extension to 600 C: about 43.6 mA. No data above that last bin are claimed as
measured current calibration. These are ramp biases at 10 C/min, not equilibrium
hold currents. Source R(T) measurements end at 283.66 C; conversion above that
point uses bounded endpoint extrapolation. Reaching 600 C and accurate physical
temperature remain unverified.

The current/power ceilings retain run 117's configured headroom; sample-voltage
headroom increases from 15 to 20 V, below the existing 30 V compliance.
These ceilings are user-requested software bounds, not validated wire ratings
or target output commands. Run 117 used at most 28.6 mA, 0.596 V and 0.017 W.
Its thinner wire did not need more current than the old wire. At the estimated
600 C bias, the resistance curve suggests roughly 2 V and 0.08 W; this is an
estimate, not a high-temperature measurement. Higher ceilings alone cannot
establish accurate or stable control. The smaller gains, reduced filter delay
and matching table are initial settings for the next trial, not proven tuning.

## Feedback correction

Fresh retry pairs now have a resistance agreement allowance of the larger of
15 mOhm and 0.5% of resistance. They **also** must agree within 5 C. The original
jump trigger remains active, and the temperature agreement check prevents the
relative resistance allowance from hiding large changes in low-TCR NiCr.
Retries and the acceptance/rejection decision are saved in control diagnostics.

The new profile uses `invalid_measurement_policy = "backoff"`: invalid feedback
pauses the ramp and integral correction and reduces current toward the 5 mA
floor using the configured downward slew. The reduction is transmitted even
when the normal command-change deadband is larger. Ten consecutive invalid
cycles still stop the run. Existing explicit `hold` and `legacy` policies are
supported. Electrical checks and raw-temperature shutdown remain active during
all acquisition attempts, including retries.

## Next experiment

Restart the updated application. Select **Ni_50_200** in Material Profile and
click **Load**. Select **TEMPERATURE** mode. Load **Ni_50_200_R_vs_T.csv** using Find R vs. T. Let the wire
cool and stabilize at the entered room temperature, then Calibrate T. Zero.
Confirm Kp 0.0002, Ki 0.000002 and Initial Current 0.005 A before starting.
Use the same mounting as run 117.

    {start_T=23; step_T=0; target_T=600; ramp_speed_min=10; hold_step_time_min=5}

Maximum Temperature 600 C is a raw indicated-temperature cutoff: an overshoot
above 600 C stops heating, even during a 600 C final hold. The profile enables
the requested range, but it cannot promise smooth or accurate control through
the unmeasured range. Save the full next run to replace the estimated bins.

Rebuild the profile and companion files without instruments:

    python -m tools.build_ni50_profile --run T:/Monajem/tds_sofia/117_Ni200_50_uncharged_cur_1
